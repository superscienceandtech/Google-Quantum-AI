## 10. Manifest design and validation

The existing P005 `ArtifactManifest` is the appropriate extension point; P013
did not create a competing JSON registry. The additive P005 change:

- Adds `ProvenanceStatus` values matching the requested states:
  `OFFICIAL_AUTHENTICATED`, `OFFICIAL_SOURCE_UNVERIFIED`,
  `UNAUTHENTICATED_MIRROR`, `LOCAL_UNVERIFIED`, `MISSING`, `CORRUPTED`, and
  `ACQUISITION_BLOCKED`.
- Adds a stable `artifact_id`, separate `source_identity`, `source_url`, and
  `authentication_evidence` fields to declarations/records. These contain
  source metadata, not secrets.
- Advances the serialized artifact-manifest schema from `"1"` to `"2"` so
  consumers can detect the additive provenance fields; declaration and
  record constructor additions remain optional/backward-compatible.
- Keeps the actual SHA-256 and expected SHA-256 as separate content-integrity
  fields. A matching hash does not set or imply `OFFICIAL_AUTHENTICATED`.
- Requires an authenticated declaration to provide an exact source identity,
  HTTPS source URL, authentication evidence reference, and expected SHA-256.
  Discovery independently checks the local bytes against that expected hash.
- Reports absent paths as `MISSING`, digest mismatches as `CORRUPTED`, and
  inaccessible/invalid paths as `ACQUISITION_BLOCKED`.
- Makes readiness assessment expose per-role provenance and integrity states.
  Each required verifier/circuit/sample role must be locally available,
  explicitly `OFFICIAL_AUTHENTICATED`, and have verified SHA-256 integrity.
  The existing missing-role, Kickmix/API, and production-adapter blockers
  remain separate.
- Preserves repository-relative path validation and symlink rejection in the
  existing artifact discovery code.

Default P005 declarations now have stable IDs and
`OFFICIAL_SOURCE_UNVERIFIED` declarations. Since each corresponding path is
absent, current discovery returns `MISSING`. They contain no invented URL,
competition ID, expected digest, or authentication evidence. The legacy
`provenance` annotation now says the canonical source is not established.

This is a deterministic runtime inventory generated from declarations and
filesystem observations, not a persisted acquisition manifest. There were no
retrieved artifacts to record. Historical mirror hashes remain in P008/P009
and §6, outside the canonical role records.
